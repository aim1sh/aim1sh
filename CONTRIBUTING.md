# Contributing

Thanks for helping improve this profile repository.

## Before opening a pull request

- Keep changes focused and preserve the README's concise structure.
- Support project, skill, and contribution claims with a link or other verifiable evidence.
- Check Markdown links and preview the rendered README.
- Do not commit credentials, private client information, or generated clutter.
- Explain what changed and why in the pull request description.

Small documentation fixes, accessibility improvements, and accurate project updates are welcome. For larger changes, open an issue first so the scope can be discussed before implementation.
